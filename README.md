# Public Assets

This repository is dedicated exclusively to hosting and serving public assets (images, media, static files, and documents).

> [!WARNING]
> **DO NOT CHANGE THIS REPOSITORY TO PRIVATE.**  
> External applications, websites, and services depend on public URLs linking directly to the files in this repository. Making this repository private will break live links, media embeds, and asset delivery across all dependent projects.

---

## Purpose & Usage

- **Exclusively for Public Assets:** Only commit assets intended for public distribution and hotlinking.
- **No Sensitive Data:** Never commit secrets, credentials, proprietary source code, or private files.
- **Maintain Public Visibility:** Ensure repository settings remain set to **Public** at all times.
